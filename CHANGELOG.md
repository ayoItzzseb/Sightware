# Changelog

## v4.1.0 — Feature wave

- **Crosshair share codes** — paste any VALORANT crosshair code to import it;
  copy one from your current crosshair to share
- **Per-app crosshair memory** — pick a preset per whitelisted app; the
  overlay swaps automatically on focus
- **Preset packs** — export/import your whole library as a single zip
- **Arc shape** — Valorant-style ring segment with an angle sweep slider
- **Preview backgrounds** — drop a screenshot behind the live preview
- **Pixel editor upgrades** — undo/redo, 32/48/64 canvases, mirror X/Y,
  persistent palette
- **Rank projection + trend sparklines** — "Diamond in ~34 matches", K/D,
  ACS and RR trends on Performance
- **Best agents by map** — computed from your own history
- **CSV export** — matches and encounters
- **Encounter notes** — attach a note to any tracked player
- **Session recap** — end-of-session summary when quitting mid-session
- **Custom dark title bar, collapsible sidebar, Ctrl+K command palette,
  UI theme variants (signal / classic / violet), first-run wizard,
  "what's new" after updates**
- **Display: color temperature slider, monitor layout diagram,
  auto-apply display profiles per whitelisted app**
- **Insta-Lock removed** (feature retired at owner request)
